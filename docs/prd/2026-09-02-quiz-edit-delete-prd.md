# 小测全状态编辑与安全删除 PRD

文档日期：2026-09-02
状态：已按用户需求实施

## 功能范围

教师端每一场未发布、进行中或已关闭的小测都提供“编辑”和“删除”。可编辑字段包括：

- 小测名称
- 题目范围（关联单元/小节）
- 作答时长
- 题目数量和难度配置
- 可见年级
- 可见班级（全年级、单班或多班）

## 数据规则

1. 编辑后的配置只用于之后新开始的作答。
2. 已开始的学生继续使用开始时保存的题目、选项、标题和截止时间快照，不被教师编辑影响。
3. 如果新题目范围无法生成指定题数的完整试卷，编辑失败且所有字段回滚。
4. 学生已开始但后来被移出可见范围时，仍可完成该次作答；结算后不能再开始下一次。
5. 没有任何作答记录的小测可物理删除。
6. 已有作答记录的小测删除时先关闭并结算进行中的作答，再执行软删除；教师和学生列表不再显示，但历史成绩、答案及快照保留。

## 验收标准

- 三种状态的小测均显示编辑和删除按钮。
- 编辑名称、范围、时长、题数、年级和班级后，列表及新作答使用新配置。
- 已开始作答在编辑前后题目和截止时间完全一致。
- 非法题数编辑返回明确错误，数据库不保存半成品。
- 删除后小测立即从教师端和学生端消失。
- 删除已有成绩的小测不会删除 `QuizSubmission`。
