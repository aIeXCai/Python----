# 小测班级可见范围 PRD

文档日期：2026-09-02
状态：已按用户需求实施
范围：信息课教师端小测管理、学生端小测访问

## 目标

教师创建或编辑尚未发布的小测时，可以在当前年级内选择全年级、单个班级或多个班级。学生只有同时满足年级和班级范围时才能看到并进入小测。

## 产品规则

1. 小测仍以一个年级为基本范围，班级是年级下的进一步限制。
2. “全年级（全选）”表示该年级所有当前及以后新增班级均可见。
3. 指定班级支持多选，例如 `1班、3班、5班`。
4. 班级选项来自该年级已注册学生的班级信息，去重并按自然数字顺序排列。
5. 旧小测升级后默认保持“全年级”，不得因升级缩小原有可见范围。
6. 教师可编辑任意状态的小测；修改后的范围用于之后新开始的作答，已开始的试卷保持不变。
7. 班级限制必须同时作用于学生列表、统计和所有直接访问接口，不能通过修改 URL 绕过。

## 教师端交互

- 小测列表新增“可见班级”列，显示“全年级”或具体班级列表。
- 新建/编辑弹窗新增“可见班级”区域。
- 默认选中“全年级（全选）”。
- 点击具体班级切换为指定范围，并可继续勾选多个班级。
- 指定范围至少保留一个班级；需要恢复全部范围时点击“全年级（全选）”。
- 若该年级尚无学生班级数据，保持全年级开放并给出说明。

## 验收标准

1. 设置为全年级时，同年级不同班级学生均能看到并进入小测。
2. 设置为 `1班、3班` 时，仅这两个班学生能看到并进入，其他班级列表为空且直接开始返回 403。
3. 教师列表准确显示全年级或多个班级。
4. 已关闭小测可先编辑班级范围再重新开放，使用编辑后的范围。
5. SQLite 和 MySQL 8.0 迁移后，旧小测的班级范围均为全年级。
