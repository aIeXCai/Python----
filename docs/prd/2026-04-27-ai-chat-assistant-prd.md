# PRD：AI 学习助手 — 在线对话功能

**版本**：v1.0 | **作者**：DEV Team | **日期**：2026-04-27

---

## 1. 背景与问题

当前平台为学生提供 AI 编程课（Python 提交判题）和信息科技课（选择题小测），但学生在做题过程中遇到疑问时，只能向老师求助。一个 50 人的课堂里，老师无法同时辅导所有学生。学生需要一个**随时在线、懂题目上下文**的 AI 辅导助手。

## 2. 目标

让学生在任何页面右下角点击打开 AI 对话面板，AI 能感知学生当前正在做的题目内容，给出针对性辅导，不掉请求、不丢上下文。

## 3. 用户故事

| 优先级 | 角色 | 需求 | 验收标准 |
|--------|------|------|----------|
| P0 | 学生 | 在任何学生页面右下角看到 AI 助手入口 | 悬浮按钮存在于所有学生路由页面 |
| P0 | 学生 | 打开对话面板，发送消息，收到 AI 回复 | 支持流式打字机效果展示 |
| P0 | 学生 | 在 AI 编程课题目页提问，AI 知道是哪个题目 | 上下文标签显示当前题目名，AI 回答与题目相关 |
| P0 | 学生 | 在信息课小测页提问，AI 知道是哪个小测 | 同上，上下文切换正确 |
| P1 | 学生 | 多条对话不混淆，可开启新对话 | 支持新建会话，历史会话独立 |
| P1 | 学生 | 网络或 API 异常时有明确提示 | 超限/失败时显示排队或错误提示 |

## 4. 资源约束

| 约束项 | 数值 | 影响 |
|--------|------|------|
| API 额度 | 1500 次/5小时 = 5 次/分钟 | 峰值时段需要排队机制 |
| 周额度 | 15,000 次 | 日均 2,100 次，正常使用足够 |
| API Key | 仅 1 个 | 不可轮转，不可扩容 |
| 课堂并发 | 最大 50 人同时在线 | 需限制后端并发防止超限 |

## 5. 功能边界

**做：**
- 学生端全局右下角悬浮聊天入口
- 基于题目/小测上下文感知的对话
- SSE 流式响应（打字机效果）
- 后端并发控制 + 排队 + 429 自动重试
- 会话管理（新建、切换、删除）

**不做：**
- 老师端 AI 对话
- 多轮对话的上下文总结/压缩
- 对话历史导出
- 对话数据统计/分析
- 语音输入/输出
- 图片/文件上传

## 6. UI/UX 规格

```
┌────────────────────────────────┐
│                                                     │
│  主页面内容                              │
│                                                     │
│                                           ┌─────┐  │
│                                           │ 💬  │  │ ← 悬浮按钮（48px 圆形）
│                                           └─────┘  │
│                                                    │
│  点击展开 ↓                                        │
│                                                    │
│  ┌──────────────────────────┐                      │
│  │ AI 学习助手    [当前题目] ✕│ ← 顶部栏 + 上下文标签│
│  │──────────────────────────│                      │
│  │                          │                      │
│  │  🤖 你好，有什么可以帮... │ ← AI 消息（左对齐）  │
│  │                 什么是变量│ ← 用户消息（右对齐）  │
│  │  🤖 变量是...            │ ← 流式逐字显示       │
│  │                          │                      │
│  │──────────────────────────│                      │
│  │ [输入框_____________] 📤 │ ← 输入栏              │
│  └──────────────────────────┘                      │
└────────────────────────────────┘
```

**交互行为：**
- 悬浮按钮：右下角固定定位，带聊天气泡图标
- 点击打开面板：宽 380px × 高 520px，从右下角滑入
- 输入：支持 Enter 发送，Shift+Enter 换行
- 上下文标签：蓝色小标签，显示"当前题目：变量与赋值"，没有上下文时隐藏
- 新建对话按钮：顶部栏"+"图标，点击清空当前会话
- 流式显示：AI 回复逐字出现，末尾闪烁光标

## 7. 非功能需求

| 类别 | 要求 |
|------|------|
| 响应时间 | 用户发消息后 < 2s 开始收到首个 token |
| 并发控制 | 后端同时最多 3 个请求打到 MiniMax |
| 排队体验 | 超过 3 个请求排队，不拒绝任何请求 |
| 错误处理 | 429 自动重试 3 次（间隔 1s/3s/5s），失败则提示用户稍后再试 |
| 密钥安全 | API Key 仅存储在服务端环境变量，前端不可见 |
| 浏览器兼容 | Chrome 最新两版本 |

## 8. 成功指标

- 学生提问后 2 秒内开始收到回复
- 课堂 50 人在线时所有请求不被拒绝（排队等待 OK）
- 上下文标签正确显示在题目页和小测页
- 每日 API 调用量不超过 2,100 次（15,000 / 7）
