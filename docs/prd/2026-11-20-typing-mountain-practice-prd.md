路线资料：[十四座八千米主峰路线核对](../prototypes/8000m-peaks/route-verification.md)

## 1. 目标与范围

在 Python 学习平台新增「打字练习」。学生用现有账号进入，分别进行最长五分钟的中文或英文单篇练习。正确输入推动登山进度，同班学生可以在左侧看本场同语言的实时海拔榜。训练默认开放。教师从首页弹窗统一配置全体班级的文章模式和中文拼音。

本版在独立本地分支和测试数据库上运行，先用一台学生机验收。正式字速标准、整班容量和素材授权另行核验。

## 2. 教师发布与课堂规则

1. 学生进入「打字训练」即可开练。班级首次使用时自动启用默认设置，中英文各用本年级基础档随机文章，中文拼音默认关闭。基础档无可用材料时使用本年级同语言的其他可用难度。教师从首页的「打字训练」卡片打开弹窗，统一保存文章模式和拼音设置。
2. 班级首次启用和每天北京时间 00:00 换山。系统从 8000 米级山峰池随机抽取当天的两座不同山峰，中文、英文各一座，并避开上一组山峰。同班同语言当天共用一座。教师调整参数时，当天山峰保持一致。跨日时已开始的练习沿用开练时的路线。
3. **文章必须与活动年级一致。**固定文章模式按年级和语言分别列出可发布篇目。学生以账号年级参加对应场次，只能选到本年级文章。后端在教师保存设置、学生选文、随机抽取和开始练习时校验年级与语言，学生端传入的年级或文章 ID 不能改变范围。当前年级题池没有可用文章时，教师端提示先补充该年级文章，本场不跨年级借题。
4. 中英文共用一种文章模式，支持以下三种模式。**固定**由教师从该年级题池选定同一篇。**随机**在该年级、同语言、同难度档的题池为每个学生分配，可碰巧分到同篇。中文随机优先抽取不少于 180 个汉字的非诗歌文章；该档全部非诗歌较短时，使用当档可用的非诗歌文章。**自由**由学生从教师指定的该年级、同语言、同档题库选文。一次练习的年级、文章分配和计分版本在开始后保持不变，刷新不会重新抽题。
5. 中文拼音由教师统一开启或关闭。开启后只在学生点击或用键盘选中某字时显示该字拼音，按词句语境标注多音字。查拼音不扣分，计时继续。英文没有拼音设置。
6. 教师保存的设置从下一次开始练习时生效。已开始的练习沿用原参数和截止时间。教师按班查询成绩留待后续实现。

## 3. 学生流程与页面布局

学生登录 → 欢迎页点击「打字训练」 → 选择中文或英文 → 预览本场山峰和规则，自由模式在此选文 → 点击开始 → 独立计时，打完整篇或五分钟到时 → 查看结果。

| 区域 | 内容和交互 |
| --- | --- |
| 登录后欢迎页 | 与现有课程入口并列显示可点击的「打字训练」卡片，卡片上始终分开显示「中文最佳成绩」和「英文最佳成绩」。显示当前学生历次有效结算中的百分制最高分，某种语言尚无成绩时显示「暂无成绩」。结算后返回欢迎页即可看到更新。当本年级缺少可用题库时，仍可查看历史成绩，训练页提示联系教师补充文章。 |
| 顶部 | 语言、山峰名称、倒计时、个人当前海拔。 右上角显示当前学生当天已结算的中英文各自最高分，按北京时间 00:00 换日。练习中可暂停，剩余时间与输入位置保留，继续练习时接着计时。「返回主页」和「开始打字」按钮大小一致，用不同颜色区分。 |
| 左侧 | 同班、同场、同语言实时榜，按海拔排序。显示姓名或班内学号、海拔和进度条，固定显示自己的位置。榜区可独立滚动，每 2 秒刷新一次，列表刷新不抢键盘焦点。个人海拔和登山路线即时更新。 |
| 右侧上方 | 在山体插画上直接叠加独立的细红线路线图层。从 BC 出发，标注 C1–C3 与该路线确有的其他营地。山体上的标记只显示节点名。学生到达对应海拔时，图上标记移动、营地点亮。登顶时显示用时。海拔显示在左榜和结算弹窗。山名右上角的「i」可打开简介，展示山脉、参考峰顶海拔、所选路线、沿途营地及资料来源。阅读简介时练习计时继续。 |
| 右侧下方 | 每个字位上行显示原文，下行实时显示学生输入，二者逐字对齐并一起折行。用文字颜色、底色及当前字位标记正确、错误与未打字符。随输入滚动，界面折行不计入字符。 |
| 结算弹窗 | 打完整篇或五分钟到时后自动弹出。顶部显示登顶状态、最终海拔、完成度或登顶用时，正文显示打字成绩、本次积分、有效字速、正确率和是否刷新个人最佳。关闭后可再次查看。 |

- 中文输入法选字完成后再判定，按 Enter 确认候选字不会提前交卷。支持退格纠错，也可点击已输入的字位或用方向键移动闪烁光标并替换字符。纠正后的字符只计一次有效工作量。点击拼音时保持输入位置与已打内容。
- 同一时间每名学生仅有一份进行中的练习。刷新恢复同一篇、已确认进度和原截止时间。短时断线提示同步状态，截止后按服务器已确认进度结算，未同步内容不作已计分显示。
- 一场练习只分配一篇文章，打完立即结算，最长五分钟。达到满分进度时海拔封顶，仍可完成当篇。

## 4. 评分、海拔与排名

- **有效输入。**中文以正确汉字计量，英文以每 5 个正确字符折算 1 个等效词（WPM）。英文大小写、空格和标点按题面比对。中文标点按题面练习，标点不增加汉字数。自动折行、粘贴和输入法未确认文本不计入有效输入。正确率以当前已输入字符中与原文匹配的比例计算，退格改对后计为正确。结算按服务端最后确认的输入计算。
- **难度折算。**满分速度按年级、语言与难度档单独配置，场次发布时保存所用规则。收集同年级试打数据后可给单篇配置速度线。不同文章时，每完成一段有效输入，都按该篇目标速度换算成「满分速度下所需秒数」。各段秒数相加后除以 300，得到进度。例如中文目标为 40 字/分钟时，打对 160 字等于 240 个目标秒，即 80%。题库编制时用于估算篇幅的字速不是评分线。若英语参数使用字符/分钟，展示与评分换算统一按 5 个字符为 1 个等效词。
- **计时与海拔。**进度为「累计目标秒 ÷ 300」，最高 100%。海拔从所选路线的 BC 参考海拔按进度线性插值到峰顶，由服务端按已确认输入计算。达到 300 个目标秒即登顶，恰好达标的输入在截止边界同样有效。当前和结算字速均按有效练习时间计算，暂停时间从中扣除。
- **同场排名。**按未四舍五入的进度排序，同进度并列。左榜用整数米展示，可出现显示相同但内部进度不同的情况。达到 100% 并列，分别保留登顶用时。每名学生只展示一行，榜单取本次实时进度与当场同语言已完成最佳成绩中的较高值，并标记该海拔来自实时进度还是已完成成绩。
- **个人和教师端。**个人主页分中英文展示最好成绩、有效字速、正确率、山峰及日期。跨课以折算后的百分制成绩比较，海拔用于展示对应场次。教师端读取同一成绩记录，按班级、场次和语言查看，标明文章版本与是否开启拼音。试用阶段的临时标准标记为「试用」，独立于后续正式最好成绩。
- **公平性验收。**试用阶段可用临时速度线验收逻辑。正式启用随机排名前，用同一批学生交叉试打同档文章，交替试打顺序，检查某篇是否持续偏快或偏慢。拼音条件不同的活动不用于同一套速度线的直接校准。

## 5. 积分提交入口

- 每次有效结算产生一条积分记录，**积分数 = 该次打字结算成绩 × 折算系数（默认 0.6）**。统一使用百分制成绩及其保存精度，例：当次成绩 82.5 分，对应 49.5 积分；达标登顶成绩 100 分，对应 60 积分。中英文和三种文章模式均适用。
- 折算原因（2026-11-24 修订）：打字可无限重复，小测一场封顶 100 分。若按成绩 1:1 计价，「每节课 2 次打字 + 1 次小测」的标准节奏下打字恒为小测两倍，道号「智识」永远出不来。折算后标准节奏约 120 : 100，两条路才可比。系数由后端 `POINTS_TYPING_WEIGHT` 控制，改口径不动代码。
- 由后端结算服务生成积分记录。预留由积分系统读取或接收的入口，提供唯一练习 ID、学生 ID、活动 ID、语言、结算成绩、积分数、规则版本和结算时间。按练习 ID 去重，结算重试、刷新和补发只认领一次。每次有效重练是独立练习，可以获得该次积分。
- 积分系统上线前保留可读取的待对接记录。实时进度、动画演示和未结算练习不产生积分。试用库记录仅用于本地验证，留在试用库内。

## 6. 文章与原软件评分资料

- 三至八年级题库以 `grade` 数值作为筛选字段，`grade_label` 只作展示。导入时对照平台账号年级映射并检查两字段一致。现有平台账号年级从七年级起；小学三至六年级开放前，需要先补齐账号、班级和教师管理范围中的相关年级，并验证现有课程权限。
- 首批候选材料见[中英文原创样文 V1](../prototypes/typing-materials/original-passages-v1.md)，每种语言 3 档、每档 2 篇。档位需经过学生试打后确认。中英文均需以多篇同档文本组成连续练习队列，标题不计入正文。
- 未取得原软件资料前，先用自编的中英文长短文进行测试。正式入库记录来源、授权、标题、原文、语言、难度和版本。中文保留整段语境，便于核对多音字。
- 取得文章后，先检查其结构、重复、标点与段落、长度分布及是否有难度标签。能一并取得的评分说明、结果页截图、用时、正确数或字速也一并核对。找不到标准时仍可按本 PRD 的可配置规则完成试用。

## 7. 本地试用与回退

- 从当前基线建立独立本地开发分支，使用单独的 SQLite 测试库和测试账号，保持现用数据库独立。
- 教师机运行本地服务。学生机连接同一允许互访的局域网，通过教师机的局域网地址访问，以学生机上的真实浏览器和中文输入法作为验收环境。
- 在教师机浏览器同时用另一个测试学生账号，辅助验证左榜两人同步。用其他班级和切换语言的账号或页面验证榜单隔离。单机试用验收操作流程，整班并发留待后续验证。
- 整班验收按约 45 人同时进入、开始打字和到时结算的场景测试，记录最旧学生机的输入反馈、素材首屏加载和榜单延迟。山景素材提前准备并可缓存，标记与路线由学生机绘制。同步传成绩摘要和时间信息，榜单更新与输入响应分开。
- 回退时停止试用服务，切回原分支并恢复原数据库配置。试用数据库单独保留，便于复盘。

## 8. 验收清单

| 场景 | 通过条件 |
| --- | --- |
| 默认开放与山峰 | 教师从未保存设置时，学生也能直接开始。教师保存后，新练习用新参数，已有练习继续按原参数走。同班同语言看到同一座山，两种语言是不同的山峰。 |
| 同班随机 | 同场两名学生抽到不同文章时仍看到同一座山。同场中文和英文为不同山峰，切换和刷新后保持对应关系。 |
| 文章及拼音 | 固定、随机和自由选文均按教师设置执行。开拼音后点字显示、成绩不扣分，关拼音时无提示入口。 |
| 文章年级限制 | 教师按年级选择固定文章，学生只看到本年级文章。手动传入其他年级的文章 ID 时，后端拒绝发布或开始练习。随机只从本年级抽取，无合格文章时提示补充。 |
| 正常输入 | 实机中文输入法可选字、英文可输入空格标点，折行顺畅，退格和点击拼音时输入焦点稳定。打完文章自动结算。 |
| 实时榜与重连 | 同班同场同语言可见，其他班级和语言隔离。刷新后文章、到期时间和已确认进度恢复，补发不会重复计分。 |
| 结算与登顶 | 五分钟自动结算，达标登顶、未达标停在对应高度。不同难度文本在等效工作量下得到相同进度。 |
| 欢迎页与记录 | 登录即见打字训练入口和两项最佳成绩。新账号两项均为「暂无成绩」。只完成中文时只更新中文，低分重练保留原最佳，英文同样独立。刷新、重新登录仍可见，同一浏览器切换账号后显示新账号自己的成绩。教师可查对应结算记录。 |
| 回退 | 停止试用并切回原分支后，原站点登录和现有课程可正常访问。 |
| 积分入口 | 每次有效结算的积分 = 该次百分制成绩 × 0.6（如 82.5 分对应 49.5 积分）。同一练习重复结算只提交一条积分记录，另一次有效练习可单独提交。 |
