# 阶段 6：数据规范与业务权限 PRD

文档日期：2026-09-04
文档状态：用户已确认（2026-09-04）
前置状态：阶段 5 的非 Docker 工作（Step 0–3、5–6）已完成；Runner 沙箱暂缓
对应路线图：阶段 6「数据规范与业务权限」

## 1. 背景与问题

平台的学生、单元、小测和成绩都依赖“年级 + 班级”判断数据范围，但目前有四类风险：

- `CustomUser.GRADE_CHOICES` 使用“初一/初二/初三”，实际数据和界面主要使用“七年级/八年级/九年级”。
- 年级、班级和学号可从多个入口以未规范字符串写入，数据库层缺少学生身份唯一约束。
- 部分接口只验证“是否为教师”，没有按 `managed_grade` 收紧查询集。
- 一些学生接口仅使用 `IsAuthenticated`，需统一检查角色、资源归属和课程范围。
- 界面同时存在“老师/教师”、繁体时间区域和英文底层状态直接展示等不一致文案。

本地 SQLite 抽查显示：学生年级为“七年级”，单元年级为“七年级/八年级”，而模型 choices 仍是“初一/初二/初三”。

## 2. 产品目标

1. 所有业务对象使用同一套年级枚举，别名只能在输入边界被兼容。
2. 学生的年级、班级和学号组合具备服务端及数据库唯一性。
3. 学生只能读写自己的作答、提交、成绩、代码任务和对话。
4. 普通教师只能读写 `managed_grade` 内的学生数据和信息课内容；缺少管理年级时默认拒绝。
5. 只有平台超级管理员可跨年级管理，普通 `is_staff` 不扩大业务权限。
6. 主要界面和业务错误统一为简体中文。
7. 用跨学生、跨班级、跨年级和角色伪造测试证明权限边界。

## 3. 非目标

- 不实施 Docker、Runner 沙箱或阿里云部署。
- 不新增校区、班主任、任课表或教师多年级/多班级授权模型。
- 不改变阶段 4 已确认的小测多次作答、最新成绩、重开和班级可见范围规则。
- 不改变 AI 编程题的评分和最高分统计口径。
- 不处理 AI 模型隐私、对话保留期和内容安全，这些属于阶段 7。
- 不删除历史业务数据；异常数据先报告，不自动合并或删除。

## 4. 角色与数据范围

### 4.1 学生

- 必须有规范年级、非空班级、非空班内学号。
- 只能访问自己的提交、成绩、小测试卷、代码任务和对话。
- 只能看到对自己年级与班级可见的小测。

### 4.2 普通教师

- `managed_grade` 是学生数据和信息课内容的服务端权限边界。
- 可管理该年级内所有班级；本阶段不增加更细的教师班级授权。
- 不能通过 URL、query string、request body 或前端隐藏控件访问其他年级。
- `managed_grade` 为空时，受限列表返回空集，详情和写操作返回 403，不默认扩大为全校范围。
- AI 编程题库当前没有年级字段，本阶段继续作为教师共享内容；AI 课学生、成绩和密码数据仍按 `managed_grade` 限制。

### 4.3 超级管理员

- `is_superuser=True` 的运维账号可跨年级访问明确允许的管理功能。
- 跨年级权限不由前端参数或 `is_staff` 单独触发。
- 超级管理操作仍需要身份认证、参数验证和审计。

## 5. 核心决策

1. **标准年级**：对外和数据库统一为“七年级、八年级、九年级、高一、高二、高三”。
2. **别名输入**：“初一/初二/初三”可在受控导入或兼容入口映射为标准值；API 返回和新写入不再产生别名，未知值直接拒绝。
3. **班级和学号是标识符**：统一去除首尾空白，不自动转整数，避免破坏“01”等合法标识。
4. **学生身份唯一**：服务端和数据库同时保证同一“年级 + 班级 + 班内学号”只有一个学生。
5. **查询集先缩小**：详情、修改、删除、密码和成绩操作先用服务端权限范围缩小 queryset，再按 ID 查找。
6. **默认拒绝**：角色不符、管理年级缺失、资源不属本人或请求跨年级时，由服务端拒绝。
7. **统一简体中文**：使用“教师”“登录”“加载”等统一术语；日期格式使用 `zh-CN`。底层英文状态码可保留，但界面需翻译。

## 6. 功能需求

### FR-01 年级规范化

- 在单一模块定义标准年级及别名映射，前后端不再分散维护不同列表。
- 覆盖 `CustomUser.grade`、`managed_grade`、`Unit.grade`、小测可见年级和提交年级快照。
- 数据 migration 在修改约束前完成别名转换，并输出行数核对、异常值清单和回滚说明。
- 历史提交年级快照必须保持可统计，不丢失成绩。

### FR-02 账号字段规则

- 注册、导入、教师编辑和 Django Admin 使用相同的验证器。
- 学生必填 `grade/class_num/student_number`；教师不使用这三个学生身份字段。
- 普通教师必须配置标准 `managed_grade`；超级管理员可为空。
- 新增条件唯一约束，防止并发注册产生重复学生身份。
- 编辑学生身份后，登录、成绩、密码恢复和历史记录仍归属同一用户 ID。

### FR-03 学生端权限

- 题目列表/详情、成绩、统计、提交和代码任务使用统一学生权限。
- 包含用户 ID、提交 ID、小测 ID 或任务 ID 的查询必须校验资源归属。
- 学生不能访问教师 API，教师不能以学生身份创建作答或代码任务。
- 修改 URL、query/body 中的年级或用户标识不能扩大访问范围。

### FR-04 教师端权限

- 学生列表、学生详情/编辑/删除、密码查看/重置、AI 成绩和信息课成绩均按 `managed_grade` 限制。
- 信息课单元、题目、小测、可见班级和统计必须与教师管理年级一致。
- 教师不能将小测发布到其他年级，也不能用其他年级的班级参数绕过。
- 越权详情和写操作返回统一错误码；列表和统计不泄露越权记录的存在性或聚合数据。
- 密码查看和重置继续遵守阶段 3 的限流、短时展示、禁止缓存和审计要求。

### FR-05 响应与隐私

- 列表序列化前必须完成权限缩小，不在序列化后靠前端隐藏。
- 学生接口不返回其他学生的姓名、学号、班级、成绩、代码、对话或小测答案。
- 越权响应不返回资源标题、所属年级或学生身份等附加信息。
- 日志可记录 actor ID、目标 ID、路径和结果，不记录密码、Token、完整代码或作答内容。

### FR-06 文案与日期

- 导航、按钮、弹窗、空状态、错误和业务状态使用简体中文。
- 统一“教师”、“登录”、“加载”、“小测”、“提交”等核心术语。
- 日期时间使用中国大陆区域表示，不在同一页混用 `zh-TW`、英文和未格式化时间。

## 7. 验收标准

### AC-01 年级一致性

- 新建、登录、编辑、导入和 API 返回均使用标准年级。
- “初一”等受支持别名在写入前转换；未知值返回 400。
- SQLite 和 MySQL 迁移后的用户、单元、小测和历史成绩行数与归属关系一致。

### AC-02 学生唯一性与登录

- 并发创建相同“年级 + 班级 + 学号”时最多成功一次。
- 输入首尾空格不会产生第二个逻辑相同账号。
- 学生编辑身份后可用新身份登录，历史数据不丢失。

### AC-03 学生横向越权

- 学生 A 无法读取或修改学生 B 的代码任务、提交、成绩、小测试卷、结果或对话。
- 学生无法访问任何教师管理接口。

### AC-04 教师跨年级越权

- 七年级教师对八年级学生的详情、编辑、删除、密码查看/重置和成绩查询全部被拒绝。
- 修改年级筛选参数不会泄露其他年级列表、总数、平均分或是否存在。
- 七年级教师无法创建、编辑、发布、重开或删除八年级信息课内容。
- 缺少 `managed_grade` 的普通教师不获得全校数据。

### AC-05 超级管理员

- 超级管理员可跨年级完成允许的管理操作。
- 普通 `is_staff` 但非超级管理员的账号不能借此绕过业务权限。

### AC-06 回归与文案

- 阶段 3 密码审计、阶段 4 小测规则和阶段 5 任务归属测试继续通过。
- 前后端全量测试、ESLint、Vite 构建和 Django 系统检查通过。
- 核心页面不再混用繁体日期区域或直接展示未翻译状态。

## 8. DEV 设计必须明确的内容

PRD 确认后，DEV 文档至少需要明确：

1. 年级常量、别名规范化函数和共享验证器。
2. SQLite/MySQL 数据 migration、异常值报告、唯一约束和回滚顺序。
3. 学生与教师 queryset scope helper、权限类和统一错误码。
4. 按接口列出的权限矩阵，包含学生、教师、无管理年级教师、`is_staff` 和超级管理员。
5. 阶段 3 密码接口和阶段 4 小测服务的收紧方式。
6. 文案搜索、日期区域替换和回归清单。
7. 分步实施、测试、数据备份和回滚计划。

## 9. 风险与缓解

- **别名转换冲突**：添加唯一约束前先报告冲突，不自动删除或合并账号。
- **权限收紧影响现有教师**：当前教师 `managed_grade` 可能为空。上线前必须配置或明确升级为超级管理员，不用默认全校权限掩盖缺失。
- **历史快照与当前年级不同**：学生升级后，历史成绩可保留提交时快照，权限判断需在 DEV 中明确使用“当前归属”还是“历史快照”。
- **403 泄露资源存在**：详情查询优先从已缩小 queryset 中查找，对外可统一为 404；审计日志保留真实拒绝原因。

## 10. PRD 确认项

确认本 PRD 即表示同意：

1. 标准年级采用“七年级/八年级/九年级/高一/高二/高三”。
2. “初一/初二/初三”仅作为受控输入别名，写入和返回统一为标准值。
3. 普通教师以单个 `managed_grade` 为权限边界，可管理该年级所有班级；缺少管理年级时默认拒绝。
4. 只有 `is_superuser=True` 可跨年级，`is_staff` 本身不扩大业务权限。
5. AI 编程题库暂作为教师共享内容，但其学生、成绩和密码数据按管理年级限制。
6. 先报告规范化冲突，不自动删除或合并用户和成绩。
7. PRD 确认后先编写 DEV 设计，DEV 再次确认后才修改数据和权限逻辑。
