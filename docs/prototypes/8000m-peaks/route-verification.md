# 十四座八千米主峰 · 课堂攀登路线核对

核对日期：2026-11-20。山峰范围采用 [UIAA 的十四座八千米主峰名单](https://www.theuiaa.org/8000m-peaks/)。每座选定一条有资料的路线。BC 表示大本营，ABC 表示前进营地，C1–C4 表示依次编号的高营。营地位置会随队伍和山况调整，表中顺序针对所列参考路线。14 座均已接入离线 Demo。图上的位置依据各自插画手动绘制。

## 原型绘图规则

- 14 座山均在各自插画上直接叠加课堂用细红线。营地顺序与参考海拔来自所列资料，红线和营地在画面上的坐标依据插画构图手动校对，未与实景照片或地理坐标配准。图上标注节点名，具体海拔在榜单和结算中展示。
- 从每座山的资料大本营海拔计起。进度适用现有百分比，按 BC 与峰顶的高差换算当前海拔。标记按对应海拔在线上移动，营地节点到达该海拔时亮起。通过的营地和登顶条件不受插画构图影响。
