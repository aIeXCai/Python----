# AI 混合小测 Step 9 完成报告：学生端作答与结果 UI

日期：2026-09-12
状态：已完成
范围：仅 Step 9；未进入 Step 10

## 完成内容

- 学生首页使用“我的小测 / 题库练习”双 Tab 切换，默认进入“我的小测”，一次只展示一个模块；小测卡片显示选择题/编程题数量、限时、状态、最近成绩和历史最好成绩。
- 新增混合作答页，统一呈现选择题和编程题导航，并支持开始、继续、倒计时、最终交卷和超时自动交卷。
- 选择题答案采用整份答案字典自动保存，带 revision 冲突处理、断网重试、离页 keepalive 和刷新恢复。
- 编程题工作区复用 Monaco 编辑器，支持标准输入、运行、正式提交、异步任务轮询、活动任务恢复、草稿本地恢复和最高分回填。
- 最终交卷前分别提示未作答选择题和尚无有效得分的编程题，并在提交过程中锁定重复操作。
- 结果页展示总分、选择题/编程题分项、编程题提交次数、错题/未答题、正确答案和解析；结算中状态会有限次数轮询。
- AI 助手在选择题页面强制关闭并禁用；仅在编程题页面启用。服务端验证小测、attempt 和题目归属，只向提示词加入公开题面、学生当前代码和最近错误，不加入正确答案或隐藏测试点。
- 学生请求层兼容空响应与非 JSON 错误响应，避免再次出现 `Unexpected end of JSON input` 类报错。

## 代码题面显示专项验收

新增统一的 `RichQuestionText` 渲染器，并用于以下位置：

- 选择题题干；
- 选择题每一个选项；
- 编程题题面；
- 结果页题干、选项与解析。

渲染器支持三反引号围栏代码块和单反引号行内代码，完整保留换行、缩进、引号以及 `<`、`>`、`&` 等字符；超宽代码块可横向滚动。内容通过 React 文本节点渲染，不使用 `dangerouslySetInnerHTML`，题库中的标签文本不会被浏览器执行。专项测试对题干和选项的原始 `textContent` 做了精确断言。

## 服务端配套调整

- 学生小测列表同时返回最近一次成绩和历史最好成绩。
- 结果接口增加编程题提交次数和是否允许重做。
- 普通编程题列表返回安全的单元名称字段，供学生题库练习筛选使用。
- 聊天接口增加 AI 小测选择题禁用和编程题上下文校验，兼容同一学生存在多个进行中小测的情况。
