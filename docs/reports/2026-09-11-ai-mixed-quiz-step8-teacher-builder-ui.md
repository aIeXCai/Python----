# AI 混合题库 Step 8 验收报告

报告日期：2026-09-11
对应 DEV：`docs/dev/2026-09-11-ai-mixed-question-bank-quiz-dev.md`
实施范围：Step 8（教师端自由组卷 UI）

## 1. 已完成能力

- AI 教师端“小测管理”已接入真实小测 API，支持按年级、状态、名称和归档状态查看小测。
- 完成五步组卷器：基本信息、选择题组卷、编程题组卷、分值与发布范围、预览并保存。
- 选择题支持按大单元/小节多选，实时预览各难度可用题量，并校验抽题数、难度比例和题池容量。
- 编程题支持关键字搜索、单元筛选、分页、多选、移除、顺序调整和逐题分值；只显示与小测年级一致且符合组卷条件的题目。
- 发布范围支持全年级、指定班级，超级管理员可选全校；发布后仍可单独调整范围。
- 草稿可新建和编辑，发布前必须通过服务端预检；支持发布、关闭、按原蓝图重开、复制为新草稿和归档。
- 首次发布后组卷内容锁定，需调整题目时引导复制新小测；编辑草稿使用 `management_version` 乐观锁。
- 本地端校验名称、时长、题型、题池、比例、分值和发布范围，并保留服务端返回的精确错误原因。
- 组卷弹窗增加未保存离开确认和页面关闭保护，避免教师误丢草稿。

## 2. 主要交付文件

- `frontend/src/pages/teacher/ai/AIQuizzesTab.jsx`：小测列表、五步组卷器、预检发布和生命周期管理。
- `frontend/src/api/aiQuiz.js`：小测 CRUD、预检、发布、关闭、重开、复制和发布范围 API 封装。
- `frontend/src/pages/teacher/aiAdmin.jsx`：向小测区域传入当前教师权限与年级信息。
- `frontend/src/pages/teacher/ai/AIQuizzesTab.test.jsx`：组卷与小测生命周期定向组件测试。
