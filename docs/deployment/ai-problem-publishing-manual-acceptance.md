# AI 题目发布管理手工验收清单

文档日期：2026-09-04
当前状态：自动化验证已通过，等待用户手工验收

## 1. 验收前准备

准备以下账号，可使用现有账号，不要在真实学生题目上试验：

- Alex 超级管理员。
- 一名 `managed_grade=七年级` 的教师。
- 一名 `managed_grade=八年级` 的教师。
- 七年级 1 班、七年级 2 班、八年级 1 班、八年级 2 班各一名测试学生。
- 一道专用测试题，题号不与正式题重复。

## 2. 教师端基础验收

1. 使用 Alex 进入“AI 课管理 → 题库管理”。
2. 确认每道题显示“可见/不可见/已暂停/已归档”之一和范围摘要。
3. 点击“编辑”，修改标题、描述、难度和初始代码并保存。
4. 刷新页面，确认内容仍在，题号不可编辑。

## 3. 精确范围验收

1. 设置“七年级 1 班 + 八年级 2 班”并保存。
2. 分别用四名测试学生登录：仅七年级 1 班和八年级 2 班可在列表看到且打开题目。
3. 把七年级改为“全选本年级所有班级”：七年级 1、2 班均可见，八年级 1 班仍不可见。
4. 选中“一键全选全校”：四名学生均可见。
5. 取消全校：原先保留的指定年级/班级范围再次生效。

## 4. 显示、隐藏与权限验收

1. Alex 点击“隐藏”：所有学生列表不显示，已保存题目 URL 打开返回 404。
2. Alex 点击“显示”：隐藏前的范围恢复。
3. 七年级教师隐藏题目：只影响七年级，八年级范围不变。
4. 七年级教师再次显示：恢复之前记住的七年级班级，不会自动放大为全年级。
5. 普通教师界面不显示全校选项，也不显示非管理年级。
6. Alex 全校规则生效时，普通教师打开范围弹窗只能看到提示，不能覆盖。

## 5. 成绩和归档验收

1. 用一名测试学生至少提交两次，确认教师成绩仍取该题历史最高分。
2. 记录该题的历史提交数，用 Alex 点击“归档”。
3. 确认学生不再看到题目，默认成绩矩阵不再显示该题列，历史提交没有被删除。
4. Alex 勾选“显示已归档”并点击“恢复”。
5. 恢复后题目仍为暂停发布；明确点击“显示”后，原范围和历史最高分重新显示。

## 6. 通过标准

- 上述所有步骤结果与预期一致。
- 没有出现跨年级范围被意外改写。
- 隐藏、调整范围、归档和恢复均不删除已有提交与成绩。
- 若界面提示“题目已被其他教师更新”，关闭弹窗刷新后可继续操作，不会覆盖他人更改。
