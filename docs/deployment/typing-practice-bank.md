# 打字登山正式题库

当前题库导出在 `typing-bank2/dist/全部.jsonl`。2026-11-20 版本的 SHA-256 为 `e0826218bf23c95f98cdac7fdd5cf8139ba70b17398780dd5ce89b028acef69d`。

发布前在目标数据库做备份。从仓库根目录运行以下命令，沿用目标环境已有的 Django 和数据库配置。

```bash
cd backend
python manage.py migrate
python manage.py release_typing_bank ../typing-bank2/dist/全部.jsonl
```

导入命令保留历史版本，只启用最终导出中标明「已核对」的篇目。重复导入同一份文件不会增加文章版本。正式题库评分线继承对应年级、语言、难度的现有试用数值，新的规则版本为 `formal-v1`。

设置 `TYPING_PRACTICE_FORMAL=1` 后重启试用服务即可启用正式题库。生产环境默认开启该配置。七、八年级已具备账号和评分线。三至六年级篇目可存入题库，在年级账号与权限开放后启用。中文开启拼音时使用已逐字核对的原创注音样文。普通练习使用正式题库。

正式练习和试用练习分别统计今日最高分、历史最高分。切换前已经开始的练习保留原材料和成绩归属。回到试用时设置 `TYPING_PRACTICE_FORMAL=0` 并重启。

教师在「参数设置」弹窗统一设置文章模式和中文拼音。固定文章模式需要分别选定中英文文章。中文随机通常从 180 字以上的非诗歌文章抽取，当前难度的非诗歌都较短时使用该难度可用的非诗歌文章。
