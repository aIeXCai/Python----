# 打字登山正式题库

当前题库导出在 `typing-bank2/dist/全部.jsonl`。2026-11-23 版（新闻题库 v3，400 篇，只含七、八年级）的 SHA-256 为 `ab88564c37b41f6811e5a827228909faeb57fc71f727ce571a3c9eef9aaa8eb5`。旧的 1,200 篇教材题库已退到 `typing-bank2/dist-legacy/全部.jsonl`，只备查。

发布前在目标数据库做备份。从仓库根目录运行以下命令，沿用目标环境已有的 Django 和数据库配置。

```bash
cd backend
python manage.py migrate
python manage.py release_typing_bank ../typing-bank2/dist/全部.jsonl
```

导入命令保留历史版本，只启用最终导出中标明「已核对」的篇目。重复导入同一份文件不会增加文章版本。正式题库评分线继承对应年级、语言、难度的现有试用数值，新的规则版本为 `formal-v1`。

设置 `TYPING_PRACTICE_FORMAL=1` 后重启试用服务即可启用正式题库。生产环境默认开启该配置。当前线上题库只有七、八年级中文英语各 100 篇，三至六年级的旧篇目不在本次导出中——发布命令会把本来源里不在清单内的旧版本统一降为待审，因此发布完成后三至六年级自然退出题池，无需手工下架。中文开启拼音时使用已逐字核对的原创注音样文。普通练习使用正式题库。

正式练习和试用练习分别统计今日最高分、历史最高分。切换前已经开始的练习保留原材料和成绩归属。回到试用时设置 `TYPING_PRACTICE_FORMAL=0` 并重启。

教师在首页点击「打字训练」打开参数设置弹窗。文章模式和中文拼音统一应用到所有班级的新练习。固定文章模式按年级分别指定中英文篇目。中文随机从 180 字以上的非诗歌文章抽取。新闻题库每篇 300 汉字以上（英文 1200 字符以上），是打满 100 分所需字数的 2.3–4 倍，手快的学生五分钟也打不完；结算仍按五分钟出分，评分口径未变。
