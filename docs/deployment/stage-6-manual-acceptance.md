# 阶段 6 手工验收清单

文档日期：2026-09-04
适用范围：本地 SQLite 联调（不需要 Docker）

## 1. 准备验收数据

先在项目 `backend` 目录创建验收数据：

```bash
python manage.py prepare_stage6_acceptance
```

第一条命令会在终端显示本次随机密码。学生用“年级 + 班级 + 学号 + 密码”登录，教师用用户名和密码登录。

然后分别打开两个终端启动后端和前端：

```bash
# 终端 1：项目 backend 目录
python manage.py runserver 8080

# 终端 2：项目 frontend 目录
npm run dev -- --host 127.0.0.1
```

浏览器访问 `http://127.0.0.1:5173`。前端会把 `/api` 请求代理到 `http://127.0.0.1:8080`，整个验收过程不需要 Docker。

## 2. 验收项目

说明：本地库中原有的 `test1`、`test` 两个小测创建于年级范围功能之前，未设置可见年级，因此对所有学生可见。判断可见性时只看 `[阶段6验收]` 前缀的小测。

注意：登录页的班级下拉只提供 1–20 班，因此验收数据统一使用 2 班（放验收小测）和 3 班（放看不到小测的学生），均在可选范围内。

| 编号 | 操作 | 预期结果 |
| --- | --- | --- |
| S6-01 | 用七年级 2 班 01 号登录 | 能看到“七年级 2 班小测”，看不到八年级小测 |
| S6-02 | 用七年级 3 班 01 号登录 | 看不到仅对 2 班可见的小测 |
| S6-03 | 用七年级学生完成小测 | 立即显示得分；答错时显示正确答案和解析 |
| S6-04 | 在浏览器地址中替换为其他学生的小测结果或任务 ID | 返回 403/404，不显示他人姓名、答案或成绩 |
| S6-05 | 用七年级验收教师打开学生管理、AI 成绩和信息课管理 | 只显示七年级数据 |
| S6-06 | 将教师页面 URL 的 `grade` 改为“八年级” | 返回空列表或 403，不显示八年级统计 |
| S6-07 | 七年级教师查看七年级学生密码，再尝试查看八年级学生密码 | 前者成功，后者被拒绝；后者不会解密密文 |
| S6-08 | 用无管理年级教师登录 | 显示“请先设置管理年级”提示，管理列表为空 |
| S6-09 | 用超级管理员 `alex` 登录 | 可切换七、八年级并查看两个年级数据 |
| S6-10 | 在学生登录请求中用“初一”代替“七年级” | 登录成功，页面和 API 均显示“七年级” |
| S6-11 | 抽查登录、学生管理、AI 提交历史和小测页 | 使用简体“教师/登录/加载”，日期是 `zh-CN`，不直接显示英文状态码 |

## 3. 验收环境

复核日期：2026-09-04

后端 `http://127.0.0.1:8080`，前端 `http://127.0.0.1:5173`（Vite 已代理 `/api` 到后端）。

启动命令（已在第 1 节列出，在项目 `backend` 与 `frontend` 目录分别执行）：

```bash
python manage.py runserver 8080
npm run dev -- --host 127.0.0.1
```

接口层已先行冒烟，以下 9 项均通过：S6-01（七年级 2 班可见验收小测）、S6-02（七年级 3 班不可见）、S6-05、S6-06、S6-07a（同年级查看密码 200）、S6-07b（跨年级查看密码 403）、S6-08、S6-10（「初一」别名登录返回七年级）。

## 4. 清理验收数据

验收完成后执行：

```bash
python manage.py prepare_stage6_acceptance --cleanup
```

该命令只删除 `stage6_accept_` 前缀账号、单元和 `[阶段6验收]` 前缀小测，不处理其他业务数据。

Runner/Docker 不在本阶段的手工验收范围内。
