# 打字登山 · 新闻题库（七、八年级）

本目录保存打字练习的可编辑源稿、构建脚本和上线文件。**上线题库为 400 篇自编新闻体练习文**：七年级、八年级，中文、英文各 100 篇。

上一版的 1,200 篇教材主题文（三至八年级）已退出上线，源稿与产物都还留着，供回溯。

## 目录

| 路径 | 内容 |
|---|---|
| `news/` | **上线题库源稿**。`zh_g7_01.py` 这种命名，每个文件 10–26 篇 |
| `news/00-编写规范.md` | 写稿口径：篇幅、结构、用词、事实要求 |
| `dist/全部.jsonl` | 上线全量，400 篇 |
| `dist/typing-bank-{zh,en}-g{7,8}.jsonl` | 分库文件 |
| `dist/00-编制规格.md` | 本版规格：与上一版差别、篇幅口径、字段、限制 |
| `dist/01-题库目录.md` | 400 篇逐篇目录（编号、栏目、标题、字数） |
| `dist/02-上线与导入说明.md` | 导入、发布、核对、回滚命令 |
| `src/` | 旧版源稿（三至八年级教材题库），不参与上线构建 |
| `dist-legacy/` | 旧版 1200 篇产物与文档，只备查 |
| `archive/` | 更早退出导出的公版短文 |

## 改稿与重建

```bash
cd typing-bank2
python3 check_shard.py news/zh_g7_02.py   # 单文件自检，必须「不合格 0 篇」
python3 build.py                          # 全量构建 + 校验，产出 dist/
python3 gen_docs.py                       # 重新生成 dist/01-题库目录.md
```

`build.py` 的篇幅带在文件顶部 `BAND`，速度假设在 `dist/00-编制规格.md` 里推导；只改这两个地方再重跑，即可调整。

## 与平台的关系

平台的导入与发布命令读取 `dist/全部.jsonl`，详见 `dist/02-上线与导入说明.md`。要点：发布命令会用本清单覆盖整个来源，**不在清单里的旧文章（含三至六年级）会被自动降为待审**，不需要另外手工下架。

## 旧版回溯

```bash
python3 build_legacy.py   # 旧 1200 篇，写入 dist-legacy/
```

旧版的规格、目录、教材对照表都在 `dist-legacy/`。
