# 三至八年级打字题库

本目录保存打字练习的可编辑源稿、构建脚本和导出文件。当前有 1,200 篇文章，中文、英文各 600 篇；每个年级、每种语言均为上下册各 50 篇。

- `src/`：按语言、年级、分册维护的文章源稿。
- `dist/全部.jsonl`：供平台导入的全量文件；`dist/typing-bank-*.jsonl` 是 12 个分年级文件。
- `dist/00-编制规格.md`、`01-题库目录.md`、`02-教材版本对照表.md`、`04-单篇试用调整.md`：规格、目录和本轮调整说明。`03-复核与改动清单.md` 是上轮历史记录。
- `archive/short-public-originals.jsonl`：六篇因长度不足而退出试用导出的公版原文，供备查，不随全量文件导入。

修改文章后，在本目录运行 `python3 build.py`、`python3 gen_catalog.py`、`python3 gen_spec.py`，再用 `python3 audit.py` 核对。平台导入命令读取 `dist/全部.jsonl`；导入后文章仍需审阅和发布，不能把干运行结果当作已入库。
